# Site da Prof.ª Eliane Coelho

Portal pessoal e didático para publicação de aulas, atividades e materiais das disciplinas de Computação.

## Como editar

- `content.js`: disciplinas, listas de materiais e links de Lattes, GitHub, LinkedIn e Instagram.
- `index.html`: apresentação pessoal e estrutura da página.
- `styles.css`: identidade visual e cores.
- `app.js`: funcionamento do menu e das janelas de materiais.
- `eliane-coelho.png`: foto usada na página inicial.

## Como publicar no GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie todos os arquivos deste pacote para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main**, a pasta **/(root)** e clique em **Save**.

O endereço será disponibilizado pelo GitHub após a publicação.
